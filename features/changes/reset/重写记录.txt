重写git commits历史记录，通过回撤修改提交的记录
> git reset 65a6f9aaa***  撤回到指定CommitID历史提交位置

> git reset --soft HEAD^   软撤回(同时保留Changes变更)
> git reset --soft HEAD~1  软撤回到前两个commit状态

> git reset --hard        默认撤回到HEAD的前一个版本(废弃当前变更changes)
> git reset --hard HEAD^  相当于删除最前面的commit
> git reset --hard HEAD~1 撤回到前两个commit状态
